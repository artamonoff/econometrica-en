# Panel data analysis with Python

Python packages for panel analysis

- [`numpy`](https://numpy.org/): Arrays, data transformation
- [`pandeas`](https://pandas.pydata.org/): DataFrames, data tables
- [`linearmodels`](https://bashtage.github.io/linearmodels/): Panel regressions fitting
- [`panelbox`](https://panelbox.readthedocs.io/en/latest/): Panel regressions fitting

`linearmodels` & `panelbox` packages can be install using the commands 

```
pip install linearmodels panelbox
``` 
or 

```
conda install -c conda-forge linearmodels panelbox
```
